# UnisGPT Downloads

Публичная страница загрузки и обновлений UnisGPT.

- APK не содержит встроенных API-ключей.
- Каждый выпуск содержит `UnisGPT.apk.sha256`.
- Android принимает обновление только с доверенной подписью приложения.

[Скачать последнюю версию](https://github.com/almaziphone/unisgpt-download/releases/latest)
